The .NET MAUI Gallery is the companion app for developers building with .NET MAUI, Microsoft's open-source framework for native apps in C# and XAML. Explore the controls, layouts and APIs in one place, running live on your device.

SEE IT RUN, NATIVELY
Every sample is a real native control, not a picture of one. A badge shows the native view each control becomes on this device, so you can see exactly what .NET MAUI renders.

PLAY WITH IT
Change the options next to each sample and watch the control update. Switch between the platform's default look and a styled one, mirror the layout for right-to-left languages, and try light and dark themes.

COPY THE CODE
The XAML and C# for each sample update as you change its options, so the code always matches what you see. Copy it straight into your app.

WHAT'S INSIDE
• Controls: buttons, text input, pickers, collections, carousels, swipe and refresh, dialogs, menus and toolbars
• Layouts: Grid, StackLayout, FlexLayout, AbsoluteLayout, Border, ScrollView and custom layouts
• Graphics: shapes, paths, brushes, shadows, clipping, transforms and the GraphicsView canvas
• Fundamentals: data binding, converters, MVVM commands, styles, themes, visual states, triggers, behaviors, animations, gestures, drag and drop, and accessibility
• Navigation: Shell, tabs, flyouts, navigation pages, multiple windows and deep links
• Device and sensors: device info, battery, connectivity, sensors, geolocation, geocoding, the flashlight, haptics and permissions
• System and sharing: clipboard, sharing, the browser, email, file and media pickers, screenshots, text-to-speech and secure storage
• Media and web: maps, images, WebView, HybridWebView and BlazorWebView
• Handlers and native views: handler customization, platform-specifics, native views and platform code
• Design guidance: color, typography, icons, spacing and responsive layouts

Search everything, save favorites, and pick up where you left off. On iPad and Mac the gallery uses a sidebar and multiple windows; on iPhone it fits in one hand.

PRIVATE BY DESIGN
No accounts, no analytics, no ads. Samples that use the camera, location or sensors only run when you open them, and nothing leaves your device.

The gallery is open source: browse the code and contribute at github.com/jfversluis/maui-gallery.
